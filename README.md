# 복합양식 편집부: 조회수 100만 챌린지

중학교 2학년 국어 수업용 모바일 게임입니다. 글에 맞는 자료를 고르고 효과를 판단해 기사 6개를 발행한 뒤 악덕 편집장 보스전에 도전합니다.

## 학생용 사이트 공개

선생님 PC에 Python, Node, 토큰을 설치하거나 설정하지 않아도 됩니다. GitHub Pages가 사이트를 공개합니다.

저장소에서 한 번만 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하세요. 이후 `main` 브랜치에 변경 사항이 올라가면 사이트가 자동으로 갱신됩니다. **Actions → Publish classroom game**에서 배포 상태와 접속 주소를 확인하고, 주소를 학생에게 QR코드로 나눠 주세요.

예정된 학생 접속 주소: https://dreamoflondonbridge-netizen.github.io/new-website/

저장소가 비공개이고 현재 GitHub 요금제가 비공개 저장소 Pages를 지원하지 않으면 Pages 설정에서 안내가 표시될 수 있습니다. 그 경우 저장소 공개 여부를 선생님이 결정해야 합니다. 이 프로젝트에서는 저장소 공개 설정을 변경하지 않습니다.

## 기록 저장 방식

게임 진행과 조회수는 각 학생 브라우저에 저장됩니다. 같은 기기와 브라우저에서 다시 열면 이어서 할 수 있습니다. 브라우저 기록을 지우거나 기기를 바꾸면 진행 데이터는 옮겨지지 않습니다. 교사용 통합 관리자, 학생 간 기록 공유, 반별 순위 다운로드 기능은 포함하지 않습니다.

처음 제공되는 기사와 문제는 수업용 샘플입니다. 사이트 시작 화면 아래 **교사용 → GitHub에서 문제 수정**을 누르면 `seed.json` 편집 화면으로 이동합니다. 이 파일을 고치고 **Commit changes**를 누르면 Pages가 다시 배포됩니다. 저장소에 쓰기 권한이 있는 GitHub 계정만 공개 문제를 바꿀 수 있습니다.

## 개발자 로컬 미리보기 (선택)

`index.html`을 브라우저에서 바로 열거나 다음처럼 임시 웹 서버를 실행할 수 있습니다. 수업 중 운영에는 필요하지 않습니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://127.0.0.1:8000/`을 엽니다.
